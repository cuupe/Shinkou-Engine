# Shinkou 数学工程工作流

## 本轮边界

本轮完善渲染、动画、编辑器、几何查询和通用数值算法能力；物理模拟与 PhysX 接入暂不修改。

## 分层设计

1. **Scalar Core**：`float` 标量、Vec、Quat、Mat、Transform 和数值策略。
2. **Geometry**：射线、平面、包围体、视锥、三角形、距离/相交/最近点和空间查询。
3. **Batch/SIMD**：保持标量参考实现，针对连续数据提供 SSE2/AVX2（可用时）和可移植回退。
4. **Parallel**：以批处理为单位调度，避免细粒度任务和重复线程创建。
5. **Algorithms**：曲线、采样、插值、分解、优化/求解等常用高级算法，按需求逐步扩展。

## 不变量

- `Mat4` 保持列主序；不改变现有 shader 上传和坐标/深度约定。
- 热路径类型保持 trivially copyable；批处理 API 不隐式分配。
- SIMD/并行结果必须与 scalar reference 在声明的误差范围内一致。
- 退化输入要有明确策略：返回 `false`、返回安全值，或显式报告错误，不能静默产生未定义结果。
- 所有尺度相关谓词使用相对/混合容差，并覆盖极小、常规、极大坐标测试。

## 每个能力的完成标准

- 公开 API、注释和使用约定；
- 正常、退化、非有限和边界输入测试；
- scalar 与 SIMD/parallel 对拍；
- 至少一个代表性批量 benchmark；
- 相关引擎测试通过；
- 记录精度、复杂度、内存和平台限制。

## 依赖决策

优先使用现有 C++ 和本地实现。只有当外部库明显提供更广算法覆盖、成熟的数值稳定性或可测得的吞吐收益时才引入，并且必须：

- 可选构建；
- 通过 Shinkou 适配层隔离；
- 不污染基础头文件的最小依赖集合；
- 有关闭依赖后的 scalar fallback。
